# Code of conduct

Short, because a long one written by somebody who is not going to enforce it is
worth less than a short one that is meant.

**Be civil and be specific.** Disagree with the code, the design or the decision
as sharply as you like — that is useful, and several of this project's better
choices came from someone saying plainly that an earlier one was wrong. Do not
make it about the person.

**Not welcome here:** harassment of any kind, insults, personal or political
attacks, publishing anyone's private information, or persistent disruption after
being asked to stop. Sexualised language and imagery are off-topic as well as
unwelcome.

**Assume the other person read the docs and still found it confusing.** That is
usually a documentation bug rather than a reading failure.

This applies in issues, pull requests, commit messages and anywhere else the
project is being discussed.

## Enforcement

There is one maintainer. Report a problem privately at kiritb@gmail.com, or
through GitHub's own reporting if it involves the maintainer. Reports stay
confidential.

Consequences are proportionate and at the maintainer's discretion: a request to
stop, a deleted comment, or a block. Nothing more elaborate is promised, because
nothing more elaborate would be true.
