- **KEEL-65** Near-duplicate titles defeat the idempotency key `p1` · storage, mcp

  Fixed. create now looks for a near-identical title in the same project and type after the exact key misses, and returns the existing artifact with created:false.
  
  The rule is overlap PLUS containment, and containment is what makes it safe: one token set must be a subset of the other, so the difference can only be added words, never substituted ones.
