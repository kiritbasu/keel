## Risks being carried

From `product/PRD.md` §11. Review at each phase gate — a risk that hasn't been looked at in three phases is either dead or ignored.

| ID | Risk | Mitigation | Watch for |
|---|---|---|---|
| R-1 | Schema creep kills it | 13 types is the ceiling; no additions for 6 months without a deletion | Wanting a 14th type — it's almost always a field or a `kind` value |
| R-2 | The agent doesn't write to it | Phase 2 is a real phase; skill and hooks are the product | Needing to remind Claude to use Keel in a session |
| R-3 | Retrieval quality is mediocre | Hybrid not pure-vector; evaluate on real queries before building UI | Searches that return plausible-but-unhelpful results |
| R-4 | Daemon is a single point of failure; GitHub is no longer an implicit backup | Backup to Parquet including Lance; mirror as legible secondary | Any session where backup didn't run |
| R-5 | Lance is the one unhedged dependency | Lance→Parquet export in P0-12 | Skipping P0-12 as "we'll do it later" |
| R-6 | Write amplification — an over-eager agent creating dozens of junk tasks | Skill emphasises consolidation; events make bulk-undo possible | A project with 40 tasks that should be 8 |
